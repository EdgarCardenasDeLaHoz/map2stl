## Quick Facts

- **Why 8.1m MAE?** Because the model sees 3 continents with different building heights. EU-only was 3.82m; global is harder but more useful.
- **Best tiles:** Lowest error 0.25m (some tiles have no buildings)
- **Worst tiles:** Highest error 60m (Cartagena has unique tall buildings)
- **Architecture**: Learned via 15-cycle grow-prune NAS
- **Phase 5 status**: Attempted high-res training but did not complete
