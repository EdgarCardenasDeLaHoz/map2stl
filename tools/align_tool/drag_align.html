Controls
Drag — move the OSM/satellite layer (STL never moves)
Wheel / + - — scale the layer (when unlocked; Ctrl+wheel is coarse)
Shift+wheel / Q E — rotate 0.1° (Ctrl+Shift+wheel: 1°)
Arrow keys — nudge 0.5 px (Shift: 5 px)
Shift+drag or middle-drag — pan the view
Alt+wheel — zoom the view
Space (hold) — hide the moving layer

Buttons
Save — writes toolslign_tool\ground_truth\<slug>.json directly (needs server.py; falls back to a browser download).
Fine-tune — runs the OpenCV ECC refine seeded with the current alignment.
Re-fetch — pulls a fresh OSM + satellite raster for the window the current alignment implies. Use it when the region is simply wrong: the pipeline sizes the window from the mesh Z range and centres it on the administrative centroid, so the true match can sit entirely outside the fetched raster.

Reference window size sets how much ground that re-fetch covers, as a multiple of the STL footprint. Raise it when the match is nowhere on screen and you need the surrounding streets to find it; 1.5× is what the pipeline itself uses. The raster resolution rises with the window, so metres-per-pixel stays roughly constant and a wider window mostly just costs fetch time.

The on-screen state maps OSM px → STL px. The export inverts it, so the saved matrix keeps the pipeline convention: 2×3 affine, STL px → OSM px, rotation about the origin (cv2.warpAffine).
