# Skyline (street-view building heights)

Locator for the skyline subsystem (street-view building heights). Its own doc is `map2stl/city2stl/skyline/README.md`. Back to the [index](../INDEX.md); paths are relative to `Code/`.

### Skyline (street-view building heights)

Everything is in `map2stl/city2stl/skyline/README.md` (overview, pipeline shape, where things live, dead ends, feature status, open items). Entry points:
- CV/geometry primitives: `map2stl/city2stl/skyline/_core/` (types, segmentation, projection, skyline, pano, registration, height). There is no façade: every caller imports the defining `_core/` or `_pano/` module.
- Building/sky masks and glass-tower hole fill: `map2stl/city2stl/skyline/_core/segmentation.py::_neural_sky_and_building_masks` (`_fill_enclosed_holes`)
- Per-view heights and aggregation: `map2stl/city2stl/skyline/_core/height.py::estimate_heights_from_registration` (`aggregate_building_heights`, `_ground_elev_m`); untagged buildings withheld (T28): `_core/height.py::withhold_untagged_street_view`, their fallback height (T41): `_core/height.py::untagged_fallback` (switch `SKYLINE_UNTAGGED_FALLBACK`, constant `UNTAGGED_FALLBACK_M`) -> `untagged_prior.py::fallback_for` (training data `data/untagged_prior_train.csv`; benchmark re-score `benchmark.py::withheld_buildings`)
- Verification tiers of published heights (F-SKY26 2a: `survey` / `corroborated` / `tag` / `single` / `prior`; `corroborated` was `verified_2` until 2026-10-09, old `heights.json` files are mapped on read by `tiers.py::upgrade_tiers` / `canonical_tier`): `map2stl/city2stl/skyline/_core/tiers.py::verification_tier` (`independent`, `INDEPENDENT` rule table, `tier_fields`, `tier_counts`); written per row by `withhold_untagged_street_view`, counted in `heights.json` by `region_pdf.py::_write_heights_json` (`HEIGHTS_SCHEMA_VERSION`)
  - Publish rules (F-SKY26, the user's choices 2026-10-08/09; decision "A single reading over 2x the prior publishes the prior unless supported"): a single over 2x the prior publishes the prior `_core/tiers.py::single_withheld` (`SINGLE_WITHHOLD_FACTOR`, `SINGLE_WITHHELD_REASON`; flag `_core/height.py::_withhold_single_enabled`, `SKYLINE_WITHHOLD_SINGLE`) unless supported `tiers.py::single_support` (`validated_satellite`, `SUPPORT_MIN_CONF`, `SUPPORT_MIN_M`, `HIGH_RISE_SUPPORT`; satellite-low veto `height.py::_satellite_low`); an `osm_tag` verified by one reading `tiers.py::tag_witness` (`TAG_WITNESS_KINDS`); untagged high-rises publish the floors height `height.py::_high_rise_height` -> `floor_bands.py::high_rise_height`
  - Cadastre plausibility band (2026-10-10; decision "The cadastre floor count bounds a single image reading"): `map2stl/city2stl/skyline/cadastre_heights.py::load_band` (`CadastreBand`, `make_band`, `STOREY_M`, `storey_m`, `cad_class`, `fetch_uses`; site flag `use_cadastre_band`, `region_data.py::_load_site_use_cadastre_band`) -> `_core/height.py::withhold_untagged_street_view(cadastre_band=)` (`tiers.py::single_outside_band`, `CADASTRE_BAND_REASON`); replaces the 2x rule where a match exists, never publishes a cadastre height.
  - Agreement rule (review item 5, 2026-10-09): `map2stl/city2stl/skyline/_core/tiers.py::agree` (`agree_tol`, `agree_band`, `log_ratio`, `AGREE_TOL` per-band table, `AGREE_BANDS`, `AGREE_FLOOR_M` / `REVIEW_FLOOR_M` floor, off); fit and labelled pairs in scratch `tiers/fit.py` / `pairs.py`. A single's satellite support uses its own looser ratio `tiers.py::SUPPORT_RATIO` (1.5).
  - Measured vs tag and selection reasons (review item 6): `tiers.py::tag_measurement` (`TAG_DISAGREE_REL`; row fields `measured_m`, `measured_methods`, `tag_disagrees`), `tiers.py::selection_reason` (`SELECTION_REASONS`; row field `selection_reason`); shown by `tier_display.py::tag_note` / `tag_disagreements` / `tag_disagreement_lines` (in `tier_hover`); `heights.json` `tag_disagreements` from `region_pdf.py::_write_heights_json`
  - Rows for drone-seen footprints with no usable reading: `region_pdf.py::_drone_seen_rows` (prior from a wider prior set `_chain_fallbacks`; weighted fields `_fill_unread_heights`)
  - Why a drone reading is left out (report column): `_pano/elevated.py::untrusted_reason`, `_mark_tower_behind` (tower behind: `tower_behind`, `_sat_max`, `behind_map`); floors in fusion: `floors_info` (high-rise flag, storey) less the counts their own seed contradicts `drop_contradicted_floors`
  - Footprint ownership of drone readings (review 2026-10-09 item 3; claims at upper plausible heights, only tags and cadastre counts take a top away, re-credit to a farther untagged owner): `map2stl/city2stl/skyline/_pano/ownership.py::Scene` (`owners`, `assess`, `recredit`; `corner_edges` diagnostic), rule `ownership.py::not_owned`, upper heights `upper_heights` / `prior_upper` (`UPPER_PRIOR_Q`, `TAG_MARGIN`), cadastre occluders `cadastre_occluders` / `cadastre_bounds` (`CADASTRE_OCCLUDERS`, `SKYLINE_CADASTRE_OCCLUDERS`), switch `OWNERSHIP` / `SKYLINE_OWNERSHIP`, per-site flags `use_ownership` / `use_cadastre_occluders` set by `ownership.set_site_flags` (on in `sites/cartagena.json`); in the run `_pano/elevated.py::seed_ownership`, `not_owned`, `_mark_not_owner`, `recredited` (applied in `elevated_estimates`)
  - Cross-sphere triangulation of roof corners (rejected on its Miami marks, off; limb-corner observation per sphere, ray intersection across camera groups): `map2stl/city2stl/skyline/_pano/triangulate.py::seed_corners` (`CornerObs`, `intersect`, `triangulate`, `fusion_reading`, `camera_group`, gates `MIN_BASELINE_M` / `MIN_ANGLE_DEG` / `MAX_MISS_M` / `MAX_VERTEX_M`, switch `TRIANGULATE` / `SKYLINE_TRIANGULATE`); in the run `_pano/elevated.py::seed_corners`, `triangulated`, `_triangulated_estimate` (pseudo-seed `TRI_SEED`); fusion source count `footprint_detect.py::fuse_heights` (kind `triangulated`)
  - Ownership harness: `Code/claude/scripts/seed_experiment.py --remeasure --own [--own-cad]` (`apply_own`, `own_metrics`)
  - Honest uncertainty (plan item 10): `mean_confidence`, `seed_disagreement_m`, `seed_std_m` are diagnostics (`region_pdf.py::DIAGNOSTIC_FIELDS`, `heights.json` `diagnostic_fields`), not accuracy; reports show `n_views` and `anchor_dev_m` (`html_report.py::_anchor_dev_cell`, `_heights_table_html` Views / Anchor dev columns; PDF `_pages.py::_render_heights_page`).   - Shown (F-SKY26 2f): labels, Okabe-Ito colours, hover text, withheld note, measured-vs-tag note `tier_display.py::tag_note` and survey licence lines in `map2stl/city2stl/skyline/tier_display.py` (`SURVEY_ATTRIBUTIONS`, `survey_attributions`); HTML index headline and table `html_report.py::_towers_table_html` / `_tier_summary_html` / `_heights_table_html`; PDF page and tier map `_region_render/_pages.py::_render_heights_page` / `_draw_tier_map` / `render_tier_map_png`; app `app/server/routers/reports.py::reports_heights` (`tier_counts`, `survey`) and `app/client/static/js/reports.js::tierSummary`
