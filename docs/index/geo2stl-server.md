# geo2stl and server internals

Locator for geo2stl (DEM, imagery, projections, water, trails) and the server-side composite, layers, regions and settings code. Back to the [index](../INDEX.md); paths are relative to `Code/`.

### geo2stl — DEM, imagery, projections, water, trails

- Metres per degree (the one home), bbox size, `GeoGrid` lon/lat ↔ pixel: `map2stl/geo2stl/geo.py::GeoGrid` (`m_per_deg_lon`, `bbox_size_m`, `bbox_diagonal_km`)
- DEM for a bbox from any source (local / h5 → SRTMGL3 fallback / OpenTopography): `map2stl/geo2stl/dem.py::fetch_dem` (`fetch_local_dem`, `fetch_h5_dem`; `shared_dim=` cuts an OpenTopography grid from `shared_base_grid` and reads ESA water at one scale for every projection); h5 tiles missing from the store filled from GEBCO / OpenTopography, else a coverage note `map2stl/geo2stl/dem.py::_fetch_h5_with_fallback` (`_h5_fill_source`)
- Depth scale + water subtraction on every DEM source; water mask (ESA, else the sea from the DEM, with a `source_note`): `map2stl/geo2stl/dem.py::apply_water_and_depth` (`water_fraction_for_dem`, `WATER_NOTE_SEA_ONLY`, `_ee_scale_floor`) — [why](../decisions/terrain-dem.md)
- Source native resolution, real samples, default source: `map2stl/geo2stl/dem.py::dem_sampling` (`native_resolution_m`, `default_dem_source`)
- Layer sources registered by the server (terrain-relative ones get `base=`): `map2stl/geo2stl/dem.py::register_layer_source` (`fetch_layer_data`, `is_terrain_relative_source`)
- DEM image/payload: `map2stl/geo2stl/dem.py::make_dem_payload` (`make_dem_image`, `compute_raw_dem`)
- OpenTopography key, datasets, request: `map2stl/geo2stl/opentopo.py::fetch_opentopo_dem` (`get_api_key`, `set_api_key`, `request_geotiff`)
- Disk cache (root `$MAP2STL_CACHE`, keys, TTLs, atomic writes, OneDrive placeholders read as a miss): `map2stl/geo2stl/cache.py::make_cache_key` (`NAMESPACE_TTL`, `_atomic_write`, `_is_cloud_placeholder`, `write_json_cache`, `read_json_cache`); app pruning `map2stl/app/server/core/cache.py::prune_cache` (`clear_bbox_cache`; npz/json pairs pruned together, orphans after `ORPHAN_GRACE_SECONDS`, cap `MAX_ENTRIES_PER_NAMESPACE`); app array writes at zlib level 1 `map2stl/app/server/core/cache.py::write_array_cache` (`_savez_fast`, `ARRAY_CACHE_ZLIB_LEVEL`, `write_array_cache_async`)
- Local tile store (is `local` usable, folder picker): `map2stl/app/server/core/tile_store.py::status` (`set_path`, `pick_folder`); routes `map2stl/app/server/routers/auth.py` (`get_tile_store`, `save_tile_store`, `browse_tile_store`)
- Tile discovery, crop, stitch: `map2stl/geo2stl/tiles.py::get_tile_files` (`stitch_tiles_no_rasterio`)
- Satellite (ESRI tiles): `map2stl/geo2stl/imagery.py::fetch_rgb` (`choose_zoom`, `fetch_tile`, `stitch_tiles`; `TILE_WORKERS` threads; tile disk cache `default_tile_cache_dir`, `_read_cached_tile`, `_write_cached_tile`); app JPEG `map2stl/geo2stl/sat2stl.py::fetch_satellite_tiles`; Earth Engine `map2stl/geo2stl/sat2stl.py::initialize_earth_engine` (`fetch_bbox_image`, `fetch_water_mask`; open water = ESA class 80 or its no-data 0, the open sea: `esa_water`); a finer cached EE image serves coarser scales `map2stl/geo2stl/sat2stl.py::_from_finer_cache` (`_resample_to_scale`)
- Projections: dispatch `map2stl/geo2stl/projections.py::project_coordinates`; grids `map2stl/geo2stl/projections.py` (`project_grid`, `project_water_arrays`, `project_rgb_image`); output size (`dim` = longest side after projection) `map2stl/geo2stl/projections.py` (`projected_shape`, `source_dim`, `source_shape`, `fit_grid`; `target_dim=` on the project functions); projection-independent shared grid (one DEM read and one river carve for every projection) `shared_source_dim`, `shared_source_shape`, `shared_covers` (cell budget `SHARED_SOURCE_MAX_FACTOR`, side cap `SHARED_SOURCE_MAX_SIDE`); separable float32 resampler used by every projection `map2stl/geo2stl/projections.py::_sample_grid` (`_sample_axis`, `_take_lerp`; matches `map_coordinates`, `tests/test_projections_remap.py`); azimuthal and conic (`laea`, `lcc`; model, extent, fallback) `map2stl/geo2stl/projections.py::_ConicAzimuthalModel` (`lcc_parameters`, `projected_fraction`, `_project_conic_azimuthal`; browser mirror `map2stl/app/client/static/js/modules/dem/graticule.js::conicAzimuthalModel`; default for large regions `map2stl/app/client/static/js/modules/dem/projection-default.js::defaultProjectionFor`, `LARGE_PROJECTION_REGION_KM`); projection wings (NaN corners) cropped from exports `map2stl/geo2stl/projections.py::largest_valid_rect` (`wing_mask`; applied by `map2stl/app/server/core/export_params.py::_crop_wings`, interim, docs/issues.md); checks `map2stl/geo2stl/projections.py::verify_layer_alignment` (`expected_aspect_ratio`) ; projected rectangle frame (F-FRAME P1; Cover / Inside / Custom, fetch bbox, `project_to_frame`; plan docs/plans/active/F-FRAME-projected-frame.md) `map2stl/geo2stl/frame.py::ProjectionModel` (`cover_frame`, `inside_frame`, `custom_frame`, `fetch_bbox`, `frame_shape`, `project_to_frame`, `needs_frame`; request parsing and fallback notices `map2stl/app/server/core/frame_params.py::parse_frame`, `resolve_frame`; JS-port fixture `map2stl/tests/fixtures/frame_cases.json`) — [reference/projections.md](../reference/projections.md)
- Layer processing and blend modes (`add` / `rivers` = raise / cut): `map2stl/geo2stl/processing.py::blend_layers` (`ProcessingSpec`, `apply_layer_processing`)
- Rivers and lakes as terrain-relative layers (F-REGION): `map2stl/geo2stl/water_layers.py::register_water_layer_sources`
  - Hydraulic geometry from discharge / order: `map2stl/geo2stl/water_layers.py::river_size_m` (`order_discharge`)
  - Valley snapping (least-cost path in a corridor): `map2stl/geo2stl/water_layers.py::snap_reaches_to_valley` (`snap_radius_m`)
  - River depth raster, thin-channel-safe resize: `map2stl/geo2stl/water_layers.py::rasterize_river_depth` (`resize_relative`)
  - River carve per Strahler order, in worker processes for large boxes (same grid): `map2stl/geo2stl/water_layers.py::river_depth_by_order` (`_carve_parallel`, `CARVE_PARALLEL_MIN`; per chunk `_carve_chunk`, burnt by the vectorised GDAL-identical fill `map2stl/geo2stl/polygon_fill.py::burn_polygons_max`, one-segment reaches as numpy GEOS-replica buffers `burn_segment_buffers_max` (`stadium_rings`, `FRAGILE_TOL_PX`), `tests/test_polygon_fill.py`; pool started before the reaches are read on big boxes: `start_carve_pool`, `CARVE_PREWARM_KM2`); cached per base order, never when empty: `river_carve_layers`; rivers preview = print carve `map2stl/app/server/routers/terrain.py::_river_print_payload` (cached only when complete: `_print_payload_complete`); carved once on the shared grid and pooled per projection without losing 1-px rivers: `map2stl/geo2stl/water_layers.py::pool_river_stack` (`pool_deepest`, `_partition_reduce`; providers flagged by `map2stl/geo2stl/dem.py::is_shared_grid_source`), last carves in memory: `_CARVE_MEMO`
  - Base DEM on the shared grid, read once per box for every projection (memory LRU, disk for OpenTopography, single flight): `map2stl/geo2stl/dem.py::shared_base_grid` (`is_shared_base_source`, `SHARED_BASE_VERSION`)
- Borders layer (country and state lines, view only): grid `map2stl/geo2stl/borders.py::borders_grid` (Natural Earth 10 m, `border_lines`; GeoJSON memo `_GEOJSON`, `_burn_lines`); route `map2stl/app/server/routers/terrain.py::get_terrain_borders`; client `map2stl/app/client/static/js/modules/layers/borders-overlay.js::loadBorders`; Edit rows `map2stl/app/client/static/js/vue/components/dem/settings/layerGroups.ts::GROUPS` (`borders`)
  - Lakes flat at shore minimum minus depth: `map2stl/geo2stl/water_layers.py::lake_depth_grid` (`make_lakes_source`; OSM up to 500 km², above it the ESA water mask: `water_mask_lakes`); still water for the 3D colours: `app/server/routers/composite.py::compute_composite_dem` (`water_out`)
- HydroRIVERS / Natural Earth: `map2stl/geo2stl/hydrology.py::fetch_hydrorivers` (`rasterize_hydrorivers_orders`, one-pass burn `_burn_orders`, `order_depth_grid`, `rasterize_hydrorivers`, `water_surface_mask`, `union_water_surface`, `fetch_natural_earth_rivers`, `HydrologyService`; an unreadable region parquet raises `HydroRiversUnavailable` from `_read_region_parquets`, never "no rivers"; an order 3+ read needs only the order 3+ parquet); route cache `map2stl/app/server/routers/terrain.py::_hydrorivers_layers` (`_hydrorivers_payload`)
- Water mask and ESA land cover (one Earth Engine fetch per box at the shared source size, `_layer_source_dim`; uint8 payloads with `*_dtype`, `map2stl/app/server/core/validation.py::b64_encode_u8`): routes `map2stl/app/server/routers/terrain.py::get_terrain_water_mask`, `get_terrain_esa_land_cover`; hydrology's open water reads the same image (`water_surface_mask` `fetch_dim`); client `map2stl/app/client/static/js/modules/layers/water-mask.js::loadEsaLandCover` reuses a cached water-mask response's ESA (`map2stl/app/client/static/js/modules/core/cache.js::waterMaskCache` `findEsa`); decoders `ui-helpers.js` (`decodeWaterMask`, `decodeEsaValues`, `decodeSatValues`)
- Trails (OSM ski + hiking, USFS), difficulty grid, mirror failover (`TrailsUpstreamError`), cache: `map2stl/geo2stl/trails.py::TrailsService` (`OsmTrailsLayer`, `UsfsTrailsLayer`, `rasterize_trails`, `_burn_difficulty`, `trails_cache_key`)
- Place search (Nominatim, ≤ 1 req/s): `map2stl/geo2stl/geocode.py::search_places`; landmarks near a box edge `map2stl/geo2stl/landmarks.py::edge_landmarks` (`fetch_edge_features`, `edge_proximity`); routes `map2stl/app/server/routers/geocode.py` (`geocode_search`, `edge_landmarks`)
- Dead code: `map2stl/geo2stl/write.py::savefile` (flips rows the live export does not)

### Server composite and layers

- Composite request (ordered layer list, failing non-base layers skipped with warnings, `RETRY_SKIPPED_S`, `COMPOSITE_CACHE_VERSION`): `map2stl/app/server/routers/composite.py::compute_composite_dem` (`merge_dem_layers`, `merge_hydrology`)
- Rivers/lakes carve kept apart (`split_carve`) and added after the export's median filter: `map2stl/app/server/routers/composite.py::compute_composite_dem`, `map2stl/app/server/core/export_params.py::mesh_composite_layers`
- City and water layer sources for geo2stl: `map2stl/app/server/routers/composite.py::register_city_layer_sources` (`register_water_sources`)
- River lines on the Edit map (view only, `#hydroShowLines`): payload `map2stl/app/server/core/river_lines.py::river_lines_payload` (`_region_reaches`, `MAX_LINES`, `MAX_POINTS`); route `map2stl/app/server/routers/terrain.py::get_terrain_river_lines`; client `map2stl/app/client/static/js/modules/layers/river-lines.js::drawRiverLines` (`visibleFrac`, `strokeRiverLines`; tests `tests/test_river_lines.py`, `tests/js/riverLines.test.js`); river colours (light cyan, dark edge) `map2stl/app/client/static/js/modules/layers/river-style.js::riverPixelColor` (`riverLineWidthPx`)
- Large-region rivers (200 km side, loading message, All warning): `map2stl/app/client/static/js/modules/layers/hydrology-print.js::LARGE_RIVER_REGION_KM` (`isLargeRiverRegion`, `riverLoadingMessage`); hint `map2stl/app/client/static/js/vue/components/dem/settings/layerGroups.ts::riversHint`; default Most `map2stl/app/server/routers/settings.py::_default_region_settings`
- River controls (one source for preview and print: source, min order, Width ×): `map2stl/app/client/static/js/modules/layers/hydrology-print.js::readHydrologyRiverControls` (`hydrologyPrintQuery`); composite sync `map2stl/app/client/static/js/modules/layers/composite-dem.js::_syncRiverParamsFromHydrology`
  - Smooth river channels (Auto / On / Off, `#compositeVectorRivers`; shallowest reach `#compositeVectorRiversMinDepthMm`, advanced): Edit rows `map2stl/app/client/static/js/vue/components/dem/settings/layerGroups.ts::GROUPS` (`water`), readers `hydrology-print.js::readVectorRivers` (`readVectorRiversMinDepthMm`), sent by `map2stl/app/client/static/js/modules/export/export-handlers.js::_exportParams`
- Client spec and panel: `map2stl/app/client/static/js/modules/layers/composite-spec.js::buildCompositeLayerSpec` (`RIVER_SOURCES`); `map2stl/app/client/static/js/modules/layers/composite-dem.js::applyCompositeToDem`; `map2stl/app/client/static/js/vue/components/dem/CompositeDemSection.vue`
- Design and status: [reference/composite-dem-design.md](../reference/composite-dem-design.md), [decisions/composite.md](../decisions/composite.md)

### Regions, settings, DEM request (server side)

- Saved regions and settings blob: `map2stl/app/server/routers/regions.py` (`list_regions`, `get_region_settings`, `save_region_settings_route`); schema `map2stl/app/server/core/db.py::init_db`
  - The one place the retired `clip_nans` key is still read (renamed to `clip_valid_region` as saved settings load): `map2stl/app/server/routers/regions.py::_rename_legacy_clip_nans`
- Default settings (`dem_source` from `default_dem_source`): `map2stl/app/server/routers/settings.py::get_default_settings`
- DEM route (returns `dem_id`, `source_resolution`, empty-DEM warning): `map2stl/app/server/routers/terrain.py::get_terrain_dem` (`_dem_empty_warning`)
- Server settings, cache paths, limits: `map2stl/app/server/config.py` (`EE_CACHE_DIR` under `geo2stl.cache.CACHE_ROOT`, `CACHE_DIRS`, `CACHE_MAX_FILES`)
- Shared in-flight dedupe (hydrology, trails): `map2stl/app/server/core/inflight.py::dedupe`
- FastAPI app, page routes: `map2stl/app/server/server.py::app` (`guides_page`, `reports_page`)
