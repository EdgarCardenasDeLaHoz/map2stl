# city2stl: city model, OSM, heights, roofs

Locator for the city2stl library: city model layers, OSM fetch and city data, building height providers, roofs and landmarks. Back to the [index](../INDEX.md); paths are relative to `Code/`.

### city2stl — city model (buildings, roads, water, trails)

- Scale ("1 mm = X m", auto true scale): `map2stl/city2stl/city_model.py::choose_scale` (`ModelScale`)
- Layer set and priority: `map2stl/city2stl/city_model.py::resolve_layers` (`LayerStyle`, `LAYER_PRIORITY`)
- Terrain in model space (projection, sampling, DEM cells under footprints): `map2stl/city2stl/city_model.py::Terrain` (`prepare_dem`, `terrain_tin`, `terrain_solid`, `terrain_tolerance`)
- Features → print polygons (line widths, min width, slenderness): `map2stl/city2stl/city_model.py::feature_polygons` (`_line_width_m`, `_widths`, `_depinch`: opens a hole touching its outline)
- Wall / fortification polygons as outline rings, cut into ground-following pieces: `map2stl/city2stl/city_model.py::split_on_ground` (`RING_LAYERS`, `WALL_PIECE_MM`) — [why](../decisions/roofs-landmarks.md)
- Flat roofs merged at one print layer (< 0.4 mm apart): `map2stl/city2stl/city_model.py::merge_flat_roofs`
- Level pads under buildings on slopes (F-PLINTH; terrain flattened before the TIN, option `level_ground`): `map2stl/city2stl/city_model.py::level_pads` (`_patch_corner_cells`, `_pad_polygons`, `PAD_MAX_DROP_MM`), wired in `build_on_terrain`; request field `app/server/core/city_model_task.py::normalize_request`; switch row `app/client/static/js/vue/components/dem/settings/layerGroups.ts` (`cityLevelGround`); tests `tests/test_city_plinth.py`
- Draped slab triangulation without Triangle (qhull + GEOS cavity recovery): `map2stl/city2stl/city_model.py::_slab` (`triangulate_polygon`, `_recover_segments`)
- One layer → solid, landmark swaps, parts: `map2stl/city2stl/city_model.py::build_layer` (`_layer_solid`, `is_part`, `assemble_parts`, `is_open_enclosure`, `MIN_LEFTOVER_WIDTH_MM`)
- Trails in the build (town / road filter; 30 m downhill run width): `map2stl/city2stl/city_model.py::filter_trails` (`_line_width_m`, `PISTE_LINE_WIDTH_M`, `is_downhill_piste`)
- Merged watertight solid, 3MF parts, lossless simplify: `map2stl/city2stl/city_model.py::assemble_model` (`welded_watertight`, `lossless_simplify`, `_separate_contacts`)
- Model caches (polygons, solids, terrain TIN, finished model; `MODEL_CACHE_VERSION`): `map2stl/city2stl/model_cache.py` (`polygons_key`, `solid_key`, `terrain_key`); finished model `map2stl/city2stl/city_model.py` (`_read_model`, `_write_model`)
- Roof solids (hipped, gabled, skillion, revolved domes/spires): `map2stl/city2stl/roofs.py::building_solids` (`convex_pieces`, `_revolved`, `_skillion_plane`)
- Vectorised flat prisms: `numpy2stl/src/numpy2stl/core/extrude.py::prisms`; streamed 3MF writer `numpy2stl/src/numpy2stl/io/writers.py::write3MF`
- Road widths (legacy helper module): `map2stl/city2stl/roads.py::get_road_width_m`

### city2stl — OSM fetch and city data

- Layer fetch (buildings, roads, water, POIs), concurrent (`_MAX_CONCURRENT_LAYERS`), mirror switched between passes, failed layers retried alone: `map2stl/city2stl/fetch.py::fetch_osm_data` (`_fetch_layers`, `_layer_jobs`)
- Fetch hooks `progress` / `on_mirror` / `should_cancel` → `map2stl/city2stl/fetch.py::FetchCancelled`
- Exhausted mirror list raises (`OverpassUpstreamError`); "nothing matched" vs "mirror refused": `map2stl/city2stl/fetch.py::OverpassUpstreamError` (`_features_or_none`) — [why](../decisions/osm-water-hydrology.md)
- Buildings keep `osm_id` + landmark tags, parts kept: `map2stl/city2stl/fetch.py::_fetch_buildings` (`_reduce_buildings_keeping_parts`); tag columns `map2stl/city2stl/heights.py::LANDMARK_TAG_COLS`
- Touching-building merge, named / historic / tower buildings kept separate: `map2stl/city2stl/heights.py::_reduce_buildings` (`keeps_own_footprint`) — [why](../decisions/roofs-landmarks.md)
- OSM lakes for the composite `lakes` layer: `map2stl/city2stl/fetch.py::fetch_osm_lakes`
- Metric reprojection (local UTM, not Mercator): `map2stl/city2stl/fetch.py::_to_metric`
- Cache version and staleness (`CITY_PIPELINE_VERSION`): `map2stl/city2stl/cache_policy.py::CITY_PIPELINE_VERSION` (`city_cache_missing_height_source`, `city_cache_stale_buildings_only`)
- Cache-first layers, size guard (no city layers > `CITY_LAYERS_MAX_DIAGONAL_KM` unless allowed), reuse of finer/enclosing entries: `map2stl/app/server/core/city_data.py::get_city_layers` (`check_city_area`, `lookup_city_layers`, `_candidates`); raster readers (composite `osm_*`, `/api/cities/raster`, enhance-heights) take any tolerance: `read_city_layers_any_tolerance`
- Coarse-tier building area floor: `map2stl/app/server/config.py::COARSE_MIN_BUILDING_AREA_M2`
- City fetch as a background job: `map2stl/app/server/core/city_fetch_tasks.py::start_city_fetch` (`cancel_task`); routes `map2stl/app/server/routers/cities.py` (`start_city_fetch`, `city_fetch_status`, `city_fetch_result`, `cancel_city_fetch`); client `map2stl/app/client/static/js/modules/layers/city-overlay.js::loadCityData` (`cancelCityFetch`), progress `map2stl/app/client/static/js/vue/components/dem/CityFetchProgress.vue`
- Overpass health probe (osmnx user agent; overpass-api.de 406s python-requests), pacing, raw QL: `map2stl/geo2stl/osm.py::healthy_overpass_endpoints` (`overpass_wait`, `overpass_backoff`, `overpass_query`)
- osmnx host pin on an address that connects (IPv6 or IPv4; osmnx pins IPv4 only): `map2stl/geo2stl/osm.py::install_dns_pin` (`pin_overpass_host`, `reachable_address`, `_pinned_getaddrinfo`), installed by `use_overpass_endpoint` and `map2stl/city2stl/osm_raster.py::_ox`
- City raster for the composite (buildings max + holes, roads, waterways, walls): `map2stl/app/server/routers/composite.py::_rasterize_city` (`_rasterize_buildings`); library version `map2stl/city2stl/rasterize.py::rasterize_city_data`

### city2stl — building heights

Overview and ranking: [reference/height-providers.md](../reference/height-providers.md); why: [decisions/building-heights.md](../decisions/building-heights.md).

- OSM tag heights, the one rule (`height` with units, else levels × 3.2 m, plus a roof level only when `roof:shape` is pitched: `has_pitched_roof_shape`): `map2stl/city2stl/heights.py::height_from_tags` (`METRES_PER_LEVEL`, `min_height_from_tags`)
- Height fill and raster enhancement per building (`height_source`): `map2stl/city2stl/heights.py::enhance_buildings_with_raster` (`_fill_heights`)
- Untagged ruins / fortress enclosures default to 3 m, not 10 m, a ruin's levels ignored (`LOW_DEFAULT_HEIGHT_M`, `is_low_default_footprint`, `is_ruin`, `default_height_for`): `map2stl/city2stl/heights.py::low_height_override`; on cached payloads (no refetch): `heights.py::apply_low_default_heights` via `map2stl/app/server/core/city_data.py::with_low_default_heights` — [why](../decisions/building-heights.md)
- Floor-count heights in cached payloads re-derived with today's roof-floor rule (no refetch): `map2stl/city2stl/heights.py::apply_levels_heights`, run first in `city_data.py::with_low_default_heights` — [why](../decisions/building-heights.md)
- Provider protocol and merge by resolution-scaled confidence; sources coarser than `BUILDING_RESOLUTION_LIMIT_M` refused: `map2stl/city2stl/height/__init__.py::merge_height_rasters` (`HeightProvider`, `HeightResult`, `resolution_priority`)
- Registry, selection, enhancement (3DEP lidar first in the US, then validated survey lidar): `map2stl/city2stl/height/service.py::enhance_city_data` (`_REGISTRY`, `_select_providers`, `_enhance_from_lidar`, `_enhance_from_survey`)
- Lidar tree canopy (`trees` layer, opt-in): data `map2stl/city2stl/canopy.py::canopy_layer` (`canopy_mask`, `CanopyParams`, `TREE_PROVIDERS`, `CANOPY_VERSION`), geometry `canopy.py::canopy_solids` and `map2stl/city2stl/city_model.py::_canopy_solid`; export switch `map2stl/app/server/core/city_model_task.py::wants_trees` — [why](../decisions/mesh-pipeline.md)
- Default-height buildings from survey lidar (Spain: CNIG `mdsn_e025` first, REDIAM MDHN only where CNIG reads under 1 m; p90 after a 1 px inward buffer, `height_source` `"survey"`): `map2stl/city2stl/height/survey_fill.py::fill_layer_heights` (all `FILL_LAYERS`: buildings, towers, churches, fortifications, walls buffered `LINE_HALF_WIDTH_M`; `fillable` = default or a bare 10.0 m `osm_tag`; other `osm_tag`/`osm_levels` rows replaced only when |survey - tag| > `TAG_OVERRIDE_MIN_DIFF_M` (3 m), tag kept in `osm_tag_height_m`; landmarks (`is_landmark`) only raised; `_burn_stats` one burn per layer; `SMALL_FOOTPRINT_M2` median; `fill_default_heights` is the buildings-only wrapper; `FILL_SOURCES`, `source_for`, `fill_resolution`, `footprint_stats`); on cached payloads: `map2stl/app/server/core/city_data.py::with_survey_heights` (in `get_city_layers`, `read_city_layers_any_tolerance`, `preflight._cached_layers`; stats in `payload["survey_fill"]`); client `layer_data` merged keeping survey heights: `city_data.py::merge_layer_data` — [why](../decisions/building-heights.md)
- Routes `/api/height/sources`, `/api/height/fetch` (import the registry from `city2stl.height.service` directly): `map2stl/app/server/routers/height.py::height_fetch` (`height_sources`)
- Providers (`map2stl/city2stl/height/providers/`):
  - Overture (module `open_buildings`): `map2stl/city2stl/height/providers/open_buildings.py::OpenBuildingsProvider`
  - GlobalBuildingAtlas (ranking vs Overture, tall-building deficit in its docstring): `map2stl/city2stl/height/providers/gba.py::GBAProvider` (`_fetch_buildings_for_bbox`, `_available_tiles`)
  - Google Photorealistic 3D Tiles: `map2stl/city2stl/height/providers/google_3d.py::Google3DProvider` (`_bv_intersects_bbox`, `_target_error_m`, `_surface_points`, `_accumulate_mesh`, `_looks_built`, `_ground_from_dsm`)
  - WSF3D 90 m + global BigTIFF fallback: `map2stl/city2stl/height/providers/wsf3d.py::WSF3DProvider` (`tiles_for_bbox`, `_global_result`), `map2stl/city2stl/height/providers/wsf3d_global.py`
  - USGS 3DEP lidar per footprint (Planetary Computer COPC): `map2stl/city2stl/height/providers/lidar_3dep_copc.py::footprint_heights` (`ndsm_for_bbox`); EPT nDSM `map2stl/city2stl/height/providers/lidar_3dep_ept.py::get_ndsm`
  - Colombian cadastre floors per footprint (AMB Cartagena `d7hk-qg8h`, LADM-COL `Construccion`; range reads, PH rule): `map2stl/city2stl/height/providers/co_catastro.py::match_footprints` (`fetch_layer`, `zip_directory`, `height_m`, `publishable`, `is_ph`, `footprint_heights`)
  - Google Open Buildings 2.5D Temporal rasters (public bucket `open-buildings-temporal-data/v1`, S2 manifests, COG windows in `~/.cache/ob25d/`; low-rise prior only, not in `_REGISTRY`): `map2stl/city2stl/height/providers/google_ob25d.py::footprint_heights` (`tiles_for_bbox`, `cell_token`, `fetch_window`, `reading_from_pixels`, `GoogleOB25DProvider`)
  - GeoTIFF reader shared by providers: `map2stl/geo2stl/raster.py::read_geotiff` (wrapped in `map2stl/city2stl/height/providers/_raster.py`)
- Survey nDSM providers, one interface `ndsm_for_bbox(bbox, res)`: `map2stl/city2stl/height/providers/survey.py::ndsm_for_bbox` (`PROVIDERS`, `available_for_bbox`); contract, grid, sanity checks, cache `map2stl/city2stl/height/providers/_survey.py` (`lonlat_grid`, `read_geotiff_array`, `cached_ndsm`); survey years per provider: `survey.py::YEARS`, `survey.py::years_for_bbox` (USGS EPT: the newest project's year)
  - France IGN `ign_lidarhd.py`, Andalucía `rediam_mdhn.py`, Spain CNIG `cnig_mdsn.py`, Czechia `cuzk_dmp.py` (the ImageServer answers square-degree pixels: `_export` warps from the returned extent); per-city sources [reference/survey-sources.md](../reference/survey-sources.md)
- Height-gap infill (linear Delaunay, nearest): `map2stl/city2stl/height/infill.py::infill_idw` (`infill_nearest`); mesh import applies it through `map2stl/app/server/core/mesh_import.py::_apply_infill`
- Georeferenced STL → heightmap: `map2stl/city2stl/height/stl_import.py::stl_to_heightmap`
- CNN height prediction/training: `map2stl/city2stl/height/predict.py::predict` — not used at runtime; see [history/ml-height/README.md](../history/ml-height/README.md)
- Provider accuracy and defect history: [issues.md](../issues.md), [decisions/building-heights.md](../decisions/building-heights.md)

### city2stl — roofs and landmarks

- City detail rows (Roof shapes, Trees, Alhambra model; F-DETAIL D5): `map2stl/app/client/static/js/modules/layers/city-detail.js::cityDetailFields` (`surveyCoverage`, `surveyCoverageReady`, `ALHAMBRA_BBOX`, `TREE_PROVIDERS`); rows in `settings/layerGroups.ts` (`city.composite`: `cityRoofShapes`, `cityTrees`, `cityAlhambra`); sent by `modules/export/export-handlers.js::_cityExtra` and `modules/layers/city-overlay.js`
- Roof shape for untagged buildings (trained GBM, then the signal cascade): `map2stl/city2stl/roof_classifier.py::classify_roof_shapes` (`_classify`, `_estimate_roof_height_from_elev`); model [reference/roof-shape-model.md](../reference/roof-shape-model.md)
  - Checkpoint loader and per-building call: `map2stl/city2stl/roof_model.py::load` (`RoofShapeModel`, `shape_for`; batched by `roof_classifier.py::_apply_model_batch`); features (order must match the checkpoint) `map2stl/city2stl/roof_features.py::FEATURES` (`extract`)
  - Zoom-18 crops and concurrent prefetch: `map2stl/city2stl/roof_tiles.py::crop_for_ring` (`prefetch_bbox`)
  - Classified roofs kept on disk per footprint (`<CACHE_ROOT>/roof_shapes.sqlite`, keyed by checkpoint hash + geometry + tags): `map2stl/city2stl/roof_cache.py::lookup` (`store`, `feature_key`, `model_id`); used by `app/server/core/city_data.py::_classify_buildings`
  - Roof detail from zoom-18 imagery (ridge direction on, hips and courtyards gated off): `map2stl/city2stl/roof_imagery.py::apply` (`measure`, `ridge_features`, `ridge_across`, `hip_features`, `courtyard_candidates`, `register_map`, `lidar_check`, `feature_key`; switches `EMIT_RIDGE` / `EMIT_HIP` / `EMIT_COURTYARDS`); raw rows in table `roof_imagery`: `map2stl/city2stl/roof_cache.py::lookup_imagery` (`store_imagery`); seam `app/server/core/city_data.py::_add_imagery`; eval `map2stl/tools/eval/eval_roof_imagery.py`; holed footprints roofed in `city2stl/roofs.py::building_solids`
  - In the app (setting `roof_shapes` auto / off, on read after the survey fill, memoised in `_roof_memo`; stats `payload["roof_shapes"]`; `merge_layer_data` keeps classified roofs): `map2stl/app/server/core/city_data.py::with_roof_shapes` (`roof_shapes_mode`, `_classify_buildings`); quick-view gable / hip `map2stl/app/client/static/js/modules/export/city-quickview.js::buildingPrisms` (`roofKind`, `roofHeightM`); tests `tests/test_roof_shapes_server.py`
  - Offline evaluation scripts (roof shape, roof tags, height rasters, shadow heights): `map2stl/tools/eval/eval_roof_classifier.py`, `eval_roof_tags.py`, `eval_pseudo_ndsm.py`, `eval_shadow_heights.py` (`python -m tools.eval.<name>`)
  - Export height score against survey truth (F-PANOVIEW; pairs by osm_id, intended `height_m` and mesh-measured, per `height_source`, plus a held-out score without `--exclude-source survey` rows): `map2stl/tools/eval/score_export_heights.py::run` (`score`, `mesh_heights`, `exclude_sources`, `load_truth`, `Georef`); pano helpers `map2stl/tools/eval/pano_manifest.py` (`bearing`, `is_google`) and `map2stl/tools/eval/render_pano_view.py` (`camera_basis`, `Scene.outside` moves a camera out of a building footprint); tests `map2stl/tests/test_score_export_heights.py`
  - Truth rebuilt provider-first with a fallback (Granada: `cnig_mdsn`, then `rediam_mdhn` where CNIG shows no building): `map2stl/city2stl/skyline/benchmark.py::FALLBACKS`, `survey_heights.py::survey_footprint_heights(fallback=)`, `scripts/19_refresh_survey_truth.py::rebuild_with_fallback` (`--rebuild-fallback`, `--offline-rings`); per-record `survey_provider`
- Landmarks (F-LANDMARK): listing `map2stl/city2stl/landmarks.py::list_landmarks` (`landmark_category`); overrides `map2stl/city2stl/landmarks.py::resolve_overrides` (`load_mesh`, `fit_mesh_xy`, `mesh_solid`, `ndsm_solid`); swap inside `build_layer` `map2stl/city2stl/landmarks.py::LandmarkPlan`; "height" kind (OSM geometry rescaled to a known top) `map2stl/city2stl/landmarks.py::scale_heights` (`override_height_m`)
  - Reference landmark (Alhambra swap from the Thingiverse model, kind `reference`, export switch `reference_landmarks`): `map2stl/city2stl/landmarks.py::reference_landmarks` (`load_reference`, `_depinch`, `_open_m` (per-unit `open_m` cutoff), `REFERENCE_MIN_M`); data `map2stl/data/landmarks/alhambra_reference.npz` + `alhambra_reference_rule.json`; builder `map2stl/tools/landmarks/build_reference_raster.py`; wired in `city_model_task.py::run_city_model`

  - Panel `map2stl/app/client/static/js/vue/components/dem/CityLandmarksSection.vue`; helpers `map2stl/app/client/static/js/modules/layers/landmark-overrides.js`
