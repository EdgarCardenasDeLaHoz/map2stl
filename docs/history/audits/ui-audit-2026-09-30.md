# UI / UX audit — 2026-09-30

Three passes, checked against researched guidelines:

- **Walkthrough** of Explore → Edit → Extrude on Granada in the browser. In-page checks measured contrast, text size, target size, names and keyboard order.
- **Static audit** of the 40 `.vue` files, `app.css` and the ES modules.
- **Re-check** of the April audits ([ux-audit.md](ux-audit.md), [accessibility-audit.md](accessibility-audit.md)).

Fixes are queued in the roadmap under "Frontend and UX" ([plans/README.md](../../plans/README.md)).

## Missed by this audit (found in use the same day)

- **Two scrollbars in the region sidebar:** the list was `height: 100%` plus the new-region form
  below it, so the panel scrolled as well as the list.
- **The new-region form was always shown:** it had the `hidden` attribute, but
  `.control-group { display: block }` overrode it.

Why they were missed: every check here was per element (contrast, size, name, focus). None
looked at how elements nest, and the screenshots were scaled down to 800 px wide. From now on,
every UI audit also runs `Code/claude/scripts/ui_layout_audit.js`. It checks for nested
scrollers, `hidden` elements that still render, unreachable off-screen controls, clipped
text and overlaps, on each tab and state. Its first run found the hover-only box editor on
the Edit tab (below).

## Guidelines used

Rules and sources, one line each. The full 50-rule list came from the research pass, from NN/g, WCAG 2.2, GOV.UK, Material 3 and PrusaSlicer.

| # | Rule | Source |
|---|---|---|
| G1 | Text contrast ≥ 4.5:1; control / focus-ring contrast ≥ 3:1 | WCAG 2.2 SC 1.4.3, 1.4.11 |
| G2 | Visible focus on every control; tab order follows the task | SC 2.4.7, 2.4.3 |
| G3 | Targets ≥ 24×24 CSS px | SC 2.5.8 |
| G4 | Every control has a name. Icon-only buttons have `aria-label` + tooltip; infrequent actions get icon + text | SC 4.1.2, NN/g icon usability |
| G5 | Body/control text ≥ 12–14 px from a small type scale | GOV.UK type scale |
| G6 | Work ≥ 10 s shows percent, stage and Cancel; 2–10 s shows a spinner | NN/g progress indicators |
| G7 | Errors that need action are inline and persist. Toasts only for passive confirmations, announced via `aria-live` | NN/g indicators vs notifications, SC 4.1.3 |
| G8 | Each view has one primary action. Essentials first, specialist settings behind "Advanced" (≤ 2 levels) | Material 3 buttons, NN/g progressive disclosure |
| G9 | Every numeric control shows its unit and the derived real-world value (printed mm) | NN/g visibility of status, SC 3.3.2 |
| G10 | A control the current mode ignores is disabled with a reason, or hidden | GOV.UK buttons, NN/g heuristics |
| G11 | One name per concept across the app | NN/g consistency |
| G12 | Size first: derive scale from the target print size / bed | PrusaSlicer-style defaults, NN/g power of defaults |
| G13 | Colour-coded layers have a legend with units | SC 1.4.1 |
| G14 | Keyboard shortcuts don't hijack typing, scrolling or browser keys. No single-letter shortcuts without a way to turn them off | SC 2.1.4 |
| G15 | `prefers-reduced-motion` respected | SC 2.3.3 / C39 |

**G1 contrast.** The April "fix" assumed a light theme. `--text-muted` #555 and `--text-dim` #333 on #2d2d2d panels measure 1.85:1 and 1.09:1. Where it shows:
- Elevation range "658 m — 852 m": 1.21:1.
- Sub-tabs View / Composite / Guide / Hide / JSON: 2.13:1.
- App title: 1.85:1.
- Preview summary line: 2.82:1.
- Hard-coded #888 (53 uses): 3.89:1.

**G11 terms.**
- The selected area is called region / bbox / box / area / bounding box.
- The elevation data is called DEM / terrain / elevation / heightmap.
- Getting data is called Load / Fetch / Reload.
- Extrude has a "📥 Fetch" sub-tab for build settings, a name also used by a sub-tab in Edit.
- Shortcut toasts say "Map / Globe / Model View", not the tab names.

**G14 shortcuts** (`keyboard-shortcuts.js`):
- Arrow keys call `preventDefault` page-wide.
- A bare `G` shortcut.
- Ctrl+R overrides browser reload.
- Escape clears the boxes even while a dialog is open.
- **Ctrl+2 crashes**: `switchView('globe')` has no null check.

## Bugs found on the way

- **Wrong continent:** Granada is grouped under **Africa**. `region-ui.js::detectContinent` puts Africa up to 38°N, which also catches southern Spain, Sicily and the Aegean. It needs a coastline test, not a latitude cut.
- **Satellite image shape:** `/api/terrain/satellite` returns 816 × 1024 px for a nearly square box, a DEM grid of 797 × 802. The raw tile image is square in degrees before projection. Overlays that stretch it to the extent still line up.
- **Duplicate ids:** `regionLabelEdit`, `saveRegionLabelBtn` and `regionLabelsList` each appear in both `SidebarEditView.vue` and `DemContainer.vue`.
- **Unused and dead code:**
  - 7 Vue components are never mounted and repeat 20 live ids.
  - 5 `window.*` hooks are called but never defined.
  - 37 `<canvas>` elements are in the DOM on the Extrude tab, 36 of them hidden.

## Priority fixes

1. **Contrast tokens:** `--text-muted` about #aaa and `--text-dim` about #9a9a9a. Replace hard-coded #888, #777 and #666 with the tokens (`app.css :root`).
2. **Keyboard access:**
   - `CollapsibleSection.vue` header becomes a `<button aria-expanded>` (28 uses).
   - A global `:focus-visible` outline and a focus style on region rows.
   - Skip the region list in tab order: a roving tabindex, one tab stop.
3. **Shortcuts:**
   - Fix the Ctrl+2 crash.
   - Scope the arrow keys to the list.
   - Drop the bare `G` and the Ctrl+R override.
   - Respect open dialogs.
4. **Toasts:** `role=status` / `alert`, errors persist until dismissed, escaped text. Validation errors move inline.
5. **Ignored and dead controls:**
   - Disable Fit height (with a reason) when Vertical ≠ Fit.
   - Implement or remove the Simplify and Surface groups controls.
6. **Size first:**
   - A printed-size readout (W × D × H mm vs bed) at the top of the Extrude settings.
   - Presets set mm/px from the bed.
   - Reword "(too small)" to "model larger than bed — enable puzzle or reduce size".
7. **Preview progress:** stage text and elapsed time on "Building mesh…", plus Cancel.
8. **Export sub-tab order:** Pre-flight open by default. The city model build is the primary action for city regions; STL / OBJ / 3MF terrain exports are secondary.
9. **Type scale:** a 12 px floor, and 24 px minimum button height.
10. **Terminology pass:**
    - One word each: "region" (and "box" for its edges), "DEM", "Load".
    - Rename Extrude's "Fetch" sub-tab to "Build".
    - Units in labels.
11. **Clean-up:**
    - Remove the duplicate-id stubs, the 7 orphan components and the legacy `#regionsContainer`.
    - Add `prefers-reduced-motion`.
12. **Bugs:** continent detection, satellite aspect.
